# AWS Static Website Hosting Project

## 📖 Description
This project demonstrates how to host a static website using **Amazon S3**. It showcases the process of deploying HTML, CSS, and JavaScript files to AWS, configuring bucket policies, and enabling public access for a live website.

---

## 🌐 Project Overview
- Built a simple static website with HTML, CSS, and JS.
- Deployed the website on **Amazon S3** using static website hosting.
- Configured bucket policies to allow public access.
- Tested deployment via the S3 endpoint URL.

---

## 🎯 Project Objectives
- Understand the fundamentals of **AWS S3 static website hosting**.
- Learn how to configure bucket permissions and policies.
- Deploy a working static website accessible over the internet.
- Document the process for portfolio and resume visibility.

---

## 🏗️ Architecture
The architecture is straightforward:
1. **Client Browser** → Requests website URL.
2. **Amazon S3 Bucket** → Serves static files (`index.html`, CSS, JS, images).
3. **Optional Enhancements**:
   - **CloudFront** for CDN + HTTPS.
   - **Route 53** for custom domain mapping.
   - **AWS Certificate Manager** for SSL/TLS.

---

## 🛠️ Technologies Used
- **Amazon S3** – Storage and static hosting.
- **AWS IAM** – Permissions and access control.
- **CloudFront (optional)** – Content delivery and HTTPS.
- **Route 53 (optional)** – Domain name system.
- **HTML, CSS, JavaScript** – Website content.

---

## 🎯 Purpose
The purpose of this project is to:
- Gain hands-on experience with AWS cloud services.
- Demonstrate ability to deploy and manage static websites.
- Build a portfolio-ready project showcasing cloud and DevOps skills.
